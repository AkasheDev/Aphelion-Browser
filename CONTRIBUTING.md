# Contributing to Aphelion

Thank you for your interest in contributing to Aphelion.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your work.
3. Make your changes and keep them focused.
4. Test your changes where possible.
5. Open a pull request with a clear description.

## Guidelines

- Use clear and descriptive commit messages.
- Keep changes small and easy to review.
- Write or update documentation when behavior changes.
- Use English for issues, pull requests, and discussion.
- Respect the project’s non-commercial licensing terms.

## Development Notes

- Mobile app work should follow Flutter and Dart best practices.
- Desktop app work should follow Avalonia and .NET conventions.
- If you are planning a larger feature, please open an issue first to discuss the approach.

## Code of Conduct

Please be respectful, constructive, and professional in all interactions.
